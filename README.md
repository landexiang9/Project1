# C语言编程练习项目

一个 C 语言入门学习项目，包含 **46 个**独立的 C 源程序，涵盖了 C 语言基础语法、算法和经典编程问题。

## 项目结构

```
Project1/
├── main.c                    # 主入口（切换调用各练习函数）
├── Project1.vcxproj          # Visual Studio 2022 项目文件
└── *.c                       # 46 个练习程序
```

## 内容分类

| 类别 | 程序 |
|------|------|
| **数学计算** | 计算圆的面积、求圆柱表面积和体积、长方形周长计算、解二次方程、华氏度转摄氏度、求sinx的近似值、计算x的n次方除以n的阶乘之和 |
| **数论与判断** | 找出一百以内能被7整除的数、求1到n中能被3和7整除的和、水仙花数判断、闰年判断、判断是否为偶数、整数位数判断 |
| **排序算法** | 冒泡排序（3种变体）、交换排序（2种变体）、三个数判断大小并排序、输入多个值排序 |
| **循环与累加** | 累加（2种）、累乘（while/do-while）、1/n累加 |
| **经典问题** | 兔子繁殖问题（斐波那契数列）、猴子吃桃、杨辉三角、金字塔打印、九九乘法表、回文串判断、分数判断、判断月份天数 |
| **字符串/字符** | 判断单词个数、字符分类统计、字符转大写 |
| **C语言基础语法示例** | printf/scanf 格式演示、运算符优先级、类型转换、逻辑运算 |

## 运行方式

使用 **Visual Studio 2022** 打开 `Project1.sln` 或 `Project1.vcxproj`，编译运行即可。

切换要执行的函数：修改 `main.c` 中调用的函数名。

## 开发环境

- IDE: Visual Studio 2022 (v143)
- 语言标准: MSVC C
- 子系统: 控制台应用程序
- 无外部依赖，仅使用 C 标准库
