# C 语言学习笔记 — 函数

## 十三、函数

### 13.1 函数的定义

```c
返回值类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}
```

**项目示例**（`计算圆的面积.c`）：

```c
double yuandemianji(double r)   // 返回 double，接受一个 double 参数
{
    double s;
    s = PEI * r * r;
    return s;                   // 返回面积值
}
```

### 13.2 函数的声明（前向声明）

如果函数的定义在使用之后，或者定义在另一个文件中，需要**提前声明**函数。

```c
返回值类型 函数名(参数类型列表);
```

**项目示例**（`main.c`）：

```c
int shichuyigeshudejueduizhi(); // 声明在输出一个数的绝对值.c 中定义

int main()
{
    shichuyigeshudejueduizhi(); // 调用其他文件的函数
    return 0;
}
```

### 13.3 函数参数

**值传递**：C 语言中函数参数默认是"值传递"——函数内修改参数不会影响原变量。

**传递数组时**：传递的是数组首地址，所以函数内可以修改原数组元素。

```c
void func(int n, int a[])   // n 是传值，a[] 传地址
{
    n = 100;                // 不影响调用者的 n
    a[0] = 999;             // 会影响调用者的数组！
}
```

### 13.4 `return` 语句

- `return 值;` — 返回一个值并退出函数
- `return;` — 仅退出函数（用于 `void` 函数）

### 13.5 `void` 函数

不返回值的函数，声明为 `void`：

```c
void maopaoapixu()
{
    // 没有 return
}
```

