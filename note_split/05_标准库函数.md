# C 语言学习笔记 — 标准库函数

## 十五、标准库函数

### 15.1 `<math.h>` 数学函数

| 函数 | 作用 | 示例 |
|------|------|------|
| `pow(x, y)` | 计算 x 的 y 次幂（返回 `double`） | `pow(2, 3)` → 8.0 |
| `fabs(x)` | 计算 double 的绝对值 | `fabs(-3.5)` → 3.5 |
| `pow(x, 0.5)` | 求平方根（无专门的 `sqrt` 时） | `pow(9, 0.5)` → 3.0 |

**项目示例**（`求sinx的近似值.c`）：

```c
fz = pow(x, n);              // x 的 n 次方
while (fabs(fz / fm) > 1e-6);// 末项绝对值小于 1e-6 时停止
```

> 使用 `math.h` 编译时需要链接数学库：`gcc -lm`。

### 15.2 输入输出函数

| 函数 | 头文件 | 作用 |

| `printf` | `stdio.h` | 格式化输出 |
| `scanf` | `stdio.h` | 格式化输入 |

| `puts` | `stdio.h` | 输出字符串加换行 |
| `gets` | `stdio.h` | 读取一行字符串（已被弃用） |
