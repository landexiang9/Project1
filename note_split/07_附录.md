# C 语言学习笔记 — 附录

## 附录：ASCII 码对照表（常用部分）

| 十进制 | 字符 | 说明 |
|-------|------|------|
| 0 | `\0` | 空字符（字符串结束标志） |
| 10 | `\n` | 换行 |
| 32 | （空格） | 空格 |
| 48~57 | `0`~`9` | 数字 0 到 9 |
| 65~90 | `A`~`Z` | 大写字母 |
| 97~122 | `a`~`z` | 小写字母 |

> **关键值**：`'a' - 'A' = 32`，`'0' = 48`

## 附录：运算符优先级（从高到低）

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1 | `()` `[]` `->` `.` | 左→右 | 函数调用、数组下标、成员访问 |
| 2 | `++` `--`（后缀） | 左→右 | 后缀自增/自减 |
| 3 | `++` `--` `+` `-` `!` `(类型)` `*` `&` `sizeof` | 右→左 | 前缀自增/减、正负号、逻辑非、类型转换、解引用、取地址、sizeof |
| 4 | `*` `/` `%` | 左→右 | 乘、除、取模 |
| 5 | `+` `-` | 左→右 | 加、减 |
| 6 | `<<` `>>` | 左→右 | 位左移、右移 |
| 7 | `<` `<=` `>` `>=` | 左→右 | 关系比较 |
| 8 | `==` `!=` | 左→右 | 相等/不等 |
| 9 | `&` | 左→右 | 按位与 |
| 10 | `^` | 左→右 | 按位异或 |
| 11 | `\|` | 左→右 | 按位或 |
| 12 | `&&` | 左→右 | 逻辑与 |
| 13 | `\|\|` | 左→右 | 逻辑或 |
| 14 | `?:` | 右→左 | 条件运算符 |
| 15 | `=` `+=` `-=` `*=` `/=` `%=` 等 | 右→左 | 赋值 |
| 16 | `,` | 左→右 | 逗号运算符 |

> **实用建议**：不要死记硬背优先级，有疑问时 **加括号** 即可。

## 附录：编译本项目

在 Linux 下编译：

```bash
gcc -o project1 -std=gnu99 $(find Project1 -name '*.c' | sort) -lm
```

- `-std=gnu99`：使用 GNU99 标准（支持 `//` 注释和 `gets`）
- `-lm`：链接数学库（提供 `pow`、`fabs`）

运行：

```bash
echo "hello world" | ./project1
```
