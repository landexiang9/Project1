# C 语言学习笔记 — 指针

## 十四、指针

指针是 C 语言的核心概念，它存储的是 **内存地址**，通过指针可以间接访问和修改变量。正确理解指针是掌握 C 语言的关键。

### 14.1 内存与地址

计算机内存以 **字节** 为单位，每个字节都有一个唯一的 **地址**（可以理解成门牌号）。变量存储在内存中，占据若干个字节，变量的 **地址** 就是它第一个字节的地址。

```c
int a = 10;
// 变量 a 占用 4 个字节（假设地址为 0x1000）
// &a 的值就是 0x1000
```

### 14.2 取地址运算符 `&`

`&` 用于获取一个变量的地址。

```c
int a;
printf("%p", &a);   // 输出变量 a 的地址（%p 是地址的格式说明符）
```

**项目中的常见用法**（`scanf` 必须传入地址）：

```c
scanf("%d", &a);   // &a 表示变量 a 的地址，scanf 将输入写入该地址
```

### 14.3 声明指针变量

声明指针的语法：

```c
类型 *指针变量名;
```

`*` 表示这是一个指针变量，`类型` 表示该指针指向的变量类型。

```c
int *p;      // p 是一个指向 int 类型变量的指针
double *q;   // q 是一个指向 double 类型变量的指针
char *r;     // r 是一个指向 char 类型变量的指针
```

> 指针变量本身也占内存（32 位系统占 4 字节，64 位系统占 8 字节），存储的是一个地址数值。

### 14.4 指针的初始化与赋值

#### 将变量的地址赋给指针

```c
int a = 10;
int *p = &a;   // 声明指针 p 并初始化为 a 的地址（p 指向 a）
```

或者先声明再赋值：

```c
int a;
int *p;
p = &a;         // p 存储 a 的地址
```

#### 指针之间可以互相赋值

**项目示例**（`访问指针所示变量示例.c`）：

```c
int a, b;
int *pa = &a;   // pa 指向 a
int *pb = &b;   // pb 指向 b

*pa = 10;       // 通过指针 pa 将 a 赋值为 10
*pb = 100;      // 通过指针 pb 将 b 赋值为 100

pb = pa;        // 将 pa 的值（a 的地址）赋给 pb，现在 pb 也指向 a
printf("a=%d,*pa=%d\n", a, *pa);   // a=10, *pa=10
printf("b=%d,*pb=%d\n", b, *pb);   // b=100, *pb=10 （pb 现在指向 a！）
```

> `pb = pa` 让两个指针指向 **同一个变量**。之后通过 `*pb` 访问的就是 `a`，不再是 `b`。

### 14.5 解引用运算符 `*`

`*` 在指针前面使用时（`*p`），表示访问指针指向的那个变量，这叫 **解引用**（dereference）。

```c
int a = 10;
int *p = &a;

printf("%d", *p);   // 解引用：输出 p 指向的变量（即 a）的值 → 10
*p = 20;            // 通过解引用赋值：等价于 a = 20
printf("%d", a);    // 输出 20
```

> `*` 在声明和表达式中含义不同：
> - `int *p;` —— 声明 p 是一个指针（`*` 是声明语法的一部分）
> - `*p = 10;` —— 对 p 解引用，写入其指向的变量（`*` 是解引用运算符）

### 14.6 通过指针读写变量的完整示例

**项目示例**（`输出一个数的绝对值.c`）：

```c
int shichuyigeshudejueduizhi()
{
    int a, *b = &a;     // 声明整型 a 和指针 b，b 指向 a
    scanf("%d", b);     // 注意：b 本身已经是指针（地址），不需要 &b
    if (*b > 0)         // 解引用 *b 获取 a 的值
        printf("%d", *b);
    else
        printf("%d", *b * -1);  // *b * -1 相当于 a * -1
    return 0;
}
```

**关键点**：
- `int *b = &a` —— 声明指针 `b` 并初始化为 `a` 的地址
- `scanf("%d", b)` —— `b` 已经是指针（地址），**不需要** 再加 `&`。这等价于 `scanf("%d", &a)`
- `*b` —— 解引用，获取 `a` 的值
- `*b * -1` —— 先解引用得到 `a` 的值，再乘以 -1

### 14.7 指针与 scanf

`scanf` 需要变量的地址才能把输入的值写入变量。通过指针可以写得更直接：

```c
int a;
int *p = &a;
scanf("%d", p);     // 等价于 scanf("%d", &a)

// 也可以直接传入指针（不需中间变量）：
int b;
int *q = &b;
scanf("%d", q);     // 从键盘读入一个整数，直接存入 b
```

**项目示例**（`例题8.4.c`）：

```c
int a, b;
int *pa = &a, *pb = &b;
scanf("%d,%d", pa, pb);   // pa 和 pb 就是地址，等价于 &a 和 &b
```

### 14.8 指针与数组名的关系

**数组名就是数组首元素的地址**。这是指针与数组之间最核心的关系。

```c
int a[10];
int *p = a;         // a 就是 &a[0]，不需要加 &
// 等价于 int *p = &a[0];
```

因此，指针可以用 **数组下标** 的方式来访问：

**项目示例**（`例题8.4.c`）：

```c
int a, b;
int *pa = &a, *pb = &b;
// pa[0] 等价于 *pa，pb[0] 等价于 *pb
if (pa[0] < pb[0])   // 比较 a 和 b 的值
{
    // 交换指针（不交换变量的值）
    pc = pa;
    pa = pb;
    pb = pc;
}
printf("最大值是：%d, 最小值是：%d, 和是：%d\n", pa[0], pb[0], pa[0] + pb[0]);
```

> 对于指向单个变量的指针，`p[0]` 和 `*p` 完全等价。`p[0]` 利用了数组下标运算符 `[]` 在指针上的通用性：`p[i]` 等价于 `*(p + i)`。

### 14.9 `NULL` 指针

`NULL` 是一个特殊值（值为 0），表示指针没有指向任何有效地址。

```c
int *p = NULL;      // 初始化指针为空，不指向任何变量
```

**项目示例**（`例题8.4.c`）：

```c
int *pc = NULL;     // 声明指针 pc 并初始化为 NULL
```

使用指针前应检查它是否为 `NULL`：

```c
if (p != NULL) {
    printf("%d", *p);   // 安全：p 有有效指向
}
```

> 解引用 `NULL` 指针会导致程序崩溃（段错误），所以声明指针后要么让它指向有效变量，要么设为 `NULL`。

### 14.10 指针的常见用途

1. **在函数间传递地址**（交换变量、修改调用者的变量）
2. **动态内存分配**（`malloc` / `free`）
3. **操作数组和字符串**（数组名就是指针常量）
4. **构建复杂数据结构**（链表、树等）
5. **提高参数传递效率**（传递大结构体的地址而非复制整个结构体）
