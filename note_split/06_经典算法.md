### 16.1 排序算法

#### 冒泡排序（升序）

核心思想：相邻元素两两比较，较大的"冒泡"到数组末尾。每轮确定一个最大元素的位置。

```c
for (i = 0; i < n - 1; i++) {
    for (j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            t = a[j]; a[j] = a[j + 1]; a[j + 1] = t;
        }
    }
}
```

**项目文件**：`冒泡排序.c`、`输入10个整数排序.c`、`输入二十个成绩并排序.c`

#### 交换排序（降序）

核心思想：固定当前位置 i，与后面每个元素比较，若更大则交换。

```c
for (i = 0; i < n - 1; i++) {
    for (j = i + 1; j < n; j++) {
        if (a[i] < a[j]) {     // 降序
            t = a[i]; a[i] = a[j]; a[j] = t;
        }
    }
}
```

**项目文件**：`交换排序1.c`、`交换排序调用.c`

#### 三个数比较排序

两两比较并交换，确保 a ≤ b ≤ c：

```c
if (a > b) { t = a; a = b; b = t; }
if (a > c) { t = a; a = c; c = t; }
if (b > c) { t = b; b = c; c = t; }
```

**项目文件**：`三个数判断大小并排序.c`

### 16.2 查找算法

#### 找最大值（擂台法）

```c
scanf("%f", &a);
max = a;                 // 第一个数当作"擂主"
for (i = 2; i <= 10; i++) {
    scanf("%f", &b);
    if (b > max)         // 挑战成功，更新擂主
        max = b;
}
```

### 16.9 指针应用

#### 通过指针输出绝对值

不直接使用变量名，而是通过指针解引用访问变量：

```c
int a, *b = &a;     // b 指向 a
scanf("%d", b);     // b 就是地址，相当于 &a
if (*b > 0)
    printf("%d", *b);
else
    printf("%d", *b * -1);
```

**项目文件**：`输出一个数的绝对值.c`

#### 通过指针间接修改变量

```c
int a, b;
int *pa = &a, *pb = &b;
*pa = 10;           // 通过 pa 修改 a
*pb = 100;          // 通过 pb 修改 b
pb = pa;            // 让 pb 也指向 a（不再指向 b）
// 现在 *pa 和 *pb 都是 a 的值
```

**项目文件**：`访问指针所示变量示例.c`

#### 通过指针比较大小并交换指向

不修改变量的值，而是交换指针的指向来实现"逻辑排序"：

```c
int a, b;
int *pa = &a, *pb = &b, *pc = NULL;
scanf("%d,%d", pa, pb);           // 通过指针读入
if (pa[0] < pb[0]) {              // pa[0] 等价于 *pa
    pc = pa;                      // 交换指针指向
    pa = pb;                      // pa 指向较大的数
    pb = pc;                      // pb 指向较小的数
}
printf("最大值：%d, 最小值：%d, 和：%d\n", pa[0], pb[0], pa[0] + pb[0]);
```
