# C 语言学习笔记 — 数组与字符串

## 十一、数组

### 11.1 一维数组

```c
类型 数组名[元素个数];
```

**项目示例**（`冒泡排序.c`）：

```c
int a[10];           // 声明一个包含 10 个 int 的数组
a[0] = 5;            // 第一个元素（索引从 0 开始）
a[9] = 3;            // 最后一个元素
```

#### 数组的初始化

```c
int a[5] = {1, 2, 3, 4, 5};
int a[]  = {1, 2, 3};       // 自动推断大小
int a[5] = {1, 2};          // 前 2 个初始化为 1,2，后 3 个为 0
```

#### 数组的遍历

```c
for (i = 0; i < 10; i++) {
    scanf("%d", &a[i]);      // 读取到数组
}

for (i = 0; i < 10; i++) {
    printf("%d ", a[i]);     // 输出数组
}
```

#### 数组作为函数参数

**项目示例**（`交换排序调用.c`）：

```c
int jiaohuanpaixudiaoyong(int n, int a[])  // a[] 接收数组
{
    // 可以直接修改 a[0], a[1] 等，修改会反映到原数组
}

// 调用：
jiaohuanpaixudiaoyong(10, a);  // 数组名作为参数
```

> 注意：数组作为参数传递时，实际上传递的是 **首地址**（指针），函数内修改数组元素会影响原数组。同时需要**额外传递数组长度**，因为函数内部无法知道数组大小。

### 11.2 二维数组

```c
类型 数组名[行数][列数];
```

**项目示例**（`杨辉三角.c`）：

```c
int a[6][6];             // 6 行 6 列的二维数组
a[t][0] = 1;             // 第 t 行第 0 列的元素
a[t][t] = 1;             // 第 t 行第 t 列的元素
a[t][i] = a[t-1][i-1] + a[t-1][i];  // 使用上一行相邻两元素
```

遍历二维数组：

```c
for (t = 0; t < 6; t++) {
    for (i = 0; i <= t; i++) {
        printf("%d ", a[t][i]);
    }
    printf("\n");
}
```

## 十二、字符串与字符处理

### 12.1 字符数组与字符串

C 语言中**没有专门的字符串类型**，字符串用字符数组来存储，以 `'\0'`（空字符，ASCII 码 0）结尾。

```c
char str[100];           // 可以存储最多 99 个字符 + 1 个 '\0'
char str[] = "hello";    // 自动分配 6 字节：'h','e','l','l','o','\0'
char str[] = {'h','e','l','l','o','\0'};  // 与上面等价
```

### 12.2 字符串输入

**`gets`（简单但不安全）**：

```c
gets(str);   // 读取一行到 str，直到遇到换行符
```

**`scanf` 的 `%s`（以空格分隔）**：

```c
scanf("%s", str);   // 读取到遇空格或换行，注意 str 前不加 &
```

### 12.3 字符串处理函数（来自 `<string.h>`）

| 函数 | 功能 | 示例 |
|------|------|------|
| `strlen(s)` | 返回字符串长度（不含 `\0`） | `n = strlen("abc");` // 3 |
| `strcmp(s1, s2)` | 比较两个字符串 | `if (strcmp(s1, s2) == 0)` // 相等 |
| `strcpy(dest, src)` | 复制字符串 | `strcpy(c2, c1);` |
| `strcat(dest, src)` | 拼接字符串 | `strcat(s1, s2);` |

#### `strcmp` 的返回值

| 返回值 | 含义 |
|--------|------|
| `< 0` | s1 小于 s2（字典序） |
| `== 0` | s1 等于 s2 |
| `> 0` | s1 大于 s2（字典序） |

**项目示例**（`回文串判断.c`）：

```c
if (strcmp(c1, c2) == 0)    // 判断两个字符串是否完全相同
    printf("same");
else
    printf("not same");
```

### 12.4 字符串遍历

**项目示例**（`判断单词个数.c`）：

```c
for (i = 0; str[i] != '\0'; i++)   // 遍历到结束符
{
    if (str[i] == ' ' && str[i + 1] != ' ' && str[i + 1] != '\0')
    {
        count++;  // 遇到空格且下一个不是空格也不是结束符 → 单词分隔
    }
}
```

### 12.5 字符串的结束符 `'\0'`

```c
c2[t] = '\0';   // 手动添加字符串结束符，否则 strcmp 会继续读取后面的垃圾值
```

> 对字符数组操作时，**必须确保末尾有 `'\0'`**，否则字符串函数会越界访问。

### 12.6 ASCII 码与字符判断

字符在内存中以 ASCII 码（整数）形式存储：

| 类别 | ASCII 码范围 | 判断写法 |
|------|-------------|---------|
| 大写字母 | 65~90（'A'~'Z'） | `ch >= 'A' && ch <= 'Z'` |
| 小写字母 | 97~122（'a'~'z'） | `ch >= 'a' && ch <= 'z'` |
| 数字 | 48~57（'0'~'9'） | `ch >= '0' && ch <= '9'` |

大小写转换：**大写 = 小写 − 32**（因为 `'a' - 'A' = 32`）

**项目示例**（`取十个字符判断各种字符的个数.c`）：

```c
if (ch >= 'A' && ch <= 'Z')
    big = big + 1;           // 大写字母
else if (ch >= 'a' && ch <= 'z')
    small = small + 1;       // 小写字母
else if (ch >= '0' && ch <= '9')
    num = num + 1;           // 数字
else
    oth = oth + 1;           // 其他字符
```

### 12.7 `puts` 输出字符串

```c
puts(c1);   // 输出 c1 的内容并自动换行
```
